 ### Hi, I'm Ahmed

  I'm a Software Engineer focused on building full stack applications and running production Kubernetes clusters on AWS/bare metal — and I also write the microservices, full-stack apps, and Discord bots that run on top of them. Most of my work revolves around GitOps, observability, and making sure
  things don't go down when they shouldn't.

  ---

  ### What I actually do

  Day to day, I spend most of my time:

  - Running and improving self-hosted Kubernetes clusters (kubeadm, Cilium with eBPF, Envoy Gateway on Gateway API)
  - Building GitOps workflows with ArgoCD (ApplicationSets, Kustomize, sync waves, PreSync DB migrations, etc.)
  - Maintaining observability stacks — Prometheus, Grafana, Loki, Alertmanager, OpenTelemetry, Hubble
  - Securing the cluster with Vault, External Secrets Operator, cert-manager, and general container hardening
  - Writing the apps that actually run on the platform — microservices, full-stack TypeScript (NestJS, Angular, Node.js), Discord bots, automation
  - Using AI tools (mostly Claude Code) to speed up repetitive platform work (manifests, debugging, scripting)

  ### Things I've built

  - **WynnAspects** — a microservices platform running on bare-metal Kubernetes
    Built with ArgoCD GitOps, Harbor registry, CloudNativePG PostgreSQL, Longhorn storage, and Cloudflare at the edge. Services are instrumented with OpenTelemetry for tracing and metrics. The application side is full-stack TypeScript — NestJS APIs, Angular SSR frontend,
  real-time WebSocket and SSE services, Valkey caching.

  - **Personal Kubernetes setup** — 2-node bare-metal cluster
    Runs e-commerce (PrestaShop + MariaDB), automation (n8n), and Discord bot workloads. Fully managed with ArgoCD ApplicationSets and Renovate, plus a full monitoring stack.

  - **GraphICE** — C# / .NET desktop app for visualizing graph algorithms
    Covers Dijkstra, Bellman-Ford, Floyd-Warshall. Built during my student years but still useful for teaching.
