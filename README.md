### Hi, I’m Ahmed

I’m a DevOps / Platform Engineer focused on building and running production Kubernetes clusters on bare metal. Most of my work revolves around GitOps, observability, and making sure things don’t go down when they shouldn’t.

---

### What I actually do

Day to day, I spend most of my time:

- Running and improving self-hosted Kubernetes clusters (kubeadm, Cilium with eBPF, Envoy Gateway on Gateway API)
- Building GitOps workflows with ArgoCD (ApplicationSets, Kustomize, sync waves, PreSync DB migrations, etc.)
- Maintaining observability stacks — Prometheus, Grafana, Loki, Alertmanager, OpenTelemetry, Hubble
- Environment secrets are securely stored with Vault, External Secrets Operator, cert-manager, and general container hardening
- Using AI tools (mostly Claude Code) to speed up repetitive platform work (manifests, debugging, scripting)

### How I think about infrastructure


I try to keep everything in Git, self-host where it actually matters (cost, control, data), and rely on external services where it doesn’t.  
When something breaks, I focus on fixing the root cause and making sure it doesn’t happen again.
